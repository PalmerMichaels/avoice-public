# Avoice Public Implementation Plan

## Scope
- Build an original TypeScript command-line app that demonstrates architecture-studio workflows inspired by Harvey-for-architecture style operations.
- Cover synthetic onboarding, workspace/project setup, architectural document/workflow screens, role/task/status flows, and mocked integrations.
- Use only clean-room, synthetic seed data created for this repository; no copied branding, logos, marketing copy, proprietary data, or private integrations.
- Keep the project runnable with `npm install`, `npm run build`, `npm start`, `npm test`, and `npm run validate`.

## Implementation Steps
- Create a strict TypeScript project with no production dependencies.
- Model fictional architecture teams, workspace setup, projects, documents, tasks, statuses, and mocked integration syncs.
- Generate a readable workflow screen report with onboarding progress, document readiness, role coverage, task flow, and next actions.
- Add validation checks that assert deterministic scores, synthetic data integrity, and disclaimer coverage.
- Document usage, seed data, and clean-room/non-regulated disclaimers in `README.md`.

## Constraints
- This is a public, clean-room implementation and does not use proprietary Avoice materials.
- This tool is not architecture, engineering, construction, legal, procurement, compliance, safety, permitting, or professional services advice.
- It is a local demo only and does not connect to external services.
